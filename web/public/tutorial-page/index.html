৮. ক্যালকুলেশন ও ব্যালেন্স চেক

৮.১ আয়-খরচ-লাভ চেক

  • সব পেমেন্টের যোগফল = মোট আয়
  • সব খরচের যোগফল = মোট খরচ
  • মোট আয় - মোট খরচ = লাভ/ক্ষতি
  • Profit Report এর সাথে Manual হিসাব মিলাও

৮.২ বিলিং ব্যালেন্স চেক

  • সব Invoice (paid + unpaid) = মোট বিল
  • Paid Invoice = প্রাপ্ত অর্থ
  • মোট বিল - প্রাপ্ত অর্থ = মোট পাওনা
  • Advance Deposit যোগ করা হয়েছে কি?

৮.৩ মেডিসিন ইনভেন্টরি চেক

  • প্রতিটি medicine এর পরিমাণ × দাম = Stock Value
  • সব medicine এর stock value যোগ = মোট inventory value
  • Dispense হওয়া medicine এর পরিমাণ × দাম = Sold Value
  • Opening + Received - Sold - Returned = Current Stock

৮.৪ ল্যাব রিপোর্ট চেক

  • আজকের মোট Order = Pending + Completed + Cancelled
  • Completed Test × Fee = Collection
  • Pending Test = Order করা হয়েছে কিন্তু Result Enter হয়নি

৮.৫ পেশেন্ট কাউন্ট চেক

  • মোট Registered Patient = Patient Table এর Count
  • আজকের Visit = আজকের Appointment + Walk-in
  • বর্তমান IPD = Active Admission

৮.৬ বেড অকুপ্যান্সি চেক

  • মোট Bed = Ward × Bed Count
  • Occupied Bed = Status = Occupied
  • Available = Total - Occupied
  • Occupancy % = (Occupied / Total) × 100

৯. ক্রস-মডিউল চেক

৯.১ Patient Linkages

  • Visit এর Patient = Patient Table এর Patient?
  • Prescription এর Patient = Patient Table এর Patient?
  • Lab Order এর Patient = Patient Table এর Patient?
  • Bill এর Patient = Patient Table এর Patient?

৯.২ Billing → Accounting

  • Invoice Paid হলে = Income Entry তৈরি হয়েছে?
  • Expense Entry হলে = Journal Entry তৈরি হয়েছে?

৯.৩ Pharmacy

  • Prescription করা হলে = Dispense করা যায়?
  • Dispense হলে = Stock কমেছে?
  • Purchase Order করলে = Stock বেড়েছে?

১০. Data Integrity চেক

  • Foreign Key: patient_id সব জায়গায় valid?
  • Orphan Record: কোনো bill এর patient_id null/invalid নেই?
  • Negative Values: কোনো stock/balance negative নেই?
  • Future Dates: কোনো admission date ভবিষ্যতে নেই?
  • Blank Fields: Name/Phone খালি নেই?

১১.১ Reference Benchmark Principles

  • Epic-style revenue cycle thinking: registration, scheduling, charging, billing, payment, patient estimate, and financial reporting should be integrated in one workflow. Reference: https://www.epic.com/software/access-and-revenue-cycle/
  • Oracle Health-style approach: front revenue cycle, clinical/financial data link, patient accounting, and near real-time operational visibility should not be separated into disconnected systems. Reference: https://www.oracle.com/health/revenue-cycle/
  • Healthcare audit control principle: systems that handle sensitive health information need user activity review, audit controls, access review, and security incident tracking. Reference: https://www.hhs.gov/hipaa/for-professionals/compliance-enforcement/audit/protocol/index.html

১৩. Financial Calculation Matrix

১৩.১ Billing Formula

line_subtotal = unit_price × quantity
invoice_subtotal = sum(line_subtotal)
invoice_total = invoice_subtotal - invoice_discount + adjustment
due = invoice_total - paid - deposit_adjusted
  • Discount কখনো subtotal-এর বেশি হবে না।
  • Paid কখনো bill total-এর বেশি হবে না; বেশি payment হলে excess deposit হবে।
  • Due কখনো negative হবে না।
  • Bill edit হলে old/new values audit log-এ থাকবে।

১৩.২ Daily Collection Formula

net_collection = CashSales - SalesReturn + DepositDeduct - ReturnDeposit + CollectionFromReceivable - CashDiscountGiven
  • Cash payment করলে payments, income, এবং emp_cash_transactions তিন জায়গায় trace থাকবে।
  • Credit note করলে income negative/reversal এবং cash transaction SalesReturn হবে।
  • Deposit refund করলে ReturnDeposit হিসেবে daily collection থেকে বাদ যাবে।
  • Cash drawer count = net cash collection হতে হবে।

১৩.৩ Deposit Formula

deposit_balance = total_deposits - total_refunds - total_adjustments
  • Admission deposit collect করলে deposit receipt তৈরি হবে।
  • Deposit adjust করলে bill due কমবে এবং deposit balance কমবে।
  • Refund amount deposit balance-এর বেশি হলে block হবে।
  • Concurrent refund/adjustment হলে negative balance হতে পারবে না।

১৩.৪ Doctor Commission Formula

gross_basis_commission = test_price × rate%
net_basis_commission = (test_price - line_discount) × rate%
fixed_commission = configured_fixed_amount
  • Commission rule doctor-wise, test-wise, department-wise configurable হতে হবে।
  • Commission final হবে payment received বা test completed policy অনুযায়ী; শুধু order দিলেই payable হবে না।
  • Status: Pending → Approved/Payable → Paid; cancel হলে Reversed।
  • Manual example: Test ৳১০০০, discount ৳১০০, net ৳৯০০, ২০% net basis = ৳১৮০।
  • Cancelled/Not Done/Refunded item payable report-এ থাকবে না।

১৩.৫ Lab Profit Formula

lab_gross_profit = lab_revenue - reagent_consumable_cost - doctor_commission - refund_adjustment
  • Completed paid tests only revenue হিসেবে ধরুন।
  • Consumable cost recipe/batch cost থেকে আসবে।
  • Cancelled tests count হবে কিন্তু revenue/profit বাড়াবে না।
  • Doctor-wise test count = completed + pending + cancelled breakdown-সহ দেখুন।

১৩.৬ Pharmacy / Inventory Formula

closing_stock = opening + purchase + sale_return - sale - supplier_return - dispatch - write_off
pharmacy_profit = net_sales - cost_of_goods_sold - return_adjustment
  • Batch/expiry ছাড়া medicine receive করা যাবে না।
  • Expired/out-of-stock sale blocked হবে।
  • Sale return stock policy অনুযায়ী usable/quarantine stock-এ যাবে।
