# Data Correction Policy

## Demographic Corrections

Name, phone, address, gender, and DOB can be corrected by authorized staff after verification. Old values must remain visible in audit history.

## Clinical Corrections

Finalized clinical data must not be silently overwritten.

- draft clinical records can be edited
- signed/final records require amendment/correction workflow
- old value remains preserved
- correction reason is mandatory
- correcting user and timestamp are mandatory

## Patient Requests

Patients can request correction from the app/portal. They cannot directly edit hospital-generated clinical records.
