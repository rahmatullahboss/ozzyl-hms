## ১. প্রকল্পের পরিচিতি

আপনার হাসপাতালের সম্পূর্ণ কার্যক্রম — রোগী ভর্তি থেকে শুরু করে বিলিং, ল্যাবরেটরি, ফার্মেসি, অ্যাকাউন্টিং এবং ম্যানেজমেন্ট রিপোর্টিং পর্যন্ত — একটি মাত্র সফটওয়্যারে পরিচালনা করার জন্য আমরা **Ozzyl HMS** প্ল্যাটফর্ম প্রস্তাব করছি।

এটি **সম্পূর্ণ custom-built, cloud-native, enterprise-grade** হাসপাতাল সফটওয়্যার — যা ইতিমধ্যে production-ready এবং **৩৭৩+ automated test** দিয়ে verified।

## ৩. সম্পূর্ণ মডিউল তালিকা (A-Z)

### 🏥 ৩.১ রোগী ম্যানেজমেন্ট (Patient Management)

- নতুন রোগী নিবন্ধন (OPD / IPD)
- রোগীর বিস্তারিত তথ্য (নাম, ঠিকানা, মোবাইল, অভিভাবক, ছবি)
- রোগী অনুসন্ধান (নাম, মোবাইল, পেশেন্ট কোড দিয়ে)
- রোগীর সম্পূর্ণ ইতিহাস (টাইমলাইন — ভিজিট, ল্যাব, বিল, প্রেসক্রিপশন)
- রোগীর ছবি আপলোড
- রোগী Self-Service পোর্টাল (রোগী নিজে রিপোর্ট, প্রেসক্রিপশন দেখতে পারবে)

### 🏠 ৩.২ রিসেপশন ও আউটডোর (Reception & OPD)

- সিরিয়াল / টোকেন ইস্যু
- Walk-in ভিজিট তৈরি
- অ্যাপয়েন্টমেন্ট শিডিউলিং
- আজকের রোগীর তালিকা (ডাক্তার অনুযায়ী)
- অ্যাপয়েন্টমেন্ট conflict চেক
- অ্যাপয়েন্টমেন্ট আপডেট / বাতিল

### 🩺 ৩.৩ ডাক্তার মডিউল (Doctor Module)

- ডাক্তারের তালিকা ও প্রোফাইল
- ডাক্তার ড্যাশবোর্ড (আজকের queue)
- শিডিউল / availability ম্যানেজমেন্ট
- কনসালটেশন নোটস
- ডিজিটাল প্রেসক্রিপশন লেখা
- প্রেসক্রিপশন PDF প্রিন্ট
- ডাক্তার কমিশন স্ট্রাকচার ও রিপোর্ট

### 🛏️ ৩.৪ ইনডোর / ভর্তি (IPD / Inpatient)

- রোগী ভর্তি (Admission)
- বেড বরাদ্দ ও ম্যানেজমেন্ট
- বেড ড্যাশবোর্ড (কোন বেড খালি, কোনটি ভর্তি)
- দৈনিক চার্জ (ওয়ার্ড, অক্সিজেন, খাবার ইত্যাদি)
- নার্স স্টেশন (ভাইটাল সাইন, ওষুধ রাউন্ড)
- ডিসচার্জ প্রসেস
- ডিসচার্জ সামারি PDF প্রিন্ট

### 🧪 ৩.৫ ল্যাবরেটরি (Laboratory)

- টেস্ট ক্যাটালগ (তৈরি / আপডেট / ডিলিট)
- ল্যাব অর্ডার তৈরি
- ল্যাব রেজাল্ট এন্ট্রি
- ল্যাব রিপোর্ট PDF প্রিন্ট
- ল্যাবরেটরি ড্যাশবোর্ড
- পেন্ডিং অর্ডার তালিকা
- আজকের টেস্ট queue

### 💊 ৩.৬ ফার্মেসি (Pharmacy)

- ওষুধের তালিকা (Medicine Master)
- সাপ্লায়ার ম্যানেজমেন্ট
- ক্রয় এন্ট্রি (Batch ও মেয়াদ সহ)
- স্টক ইন / স্টক আউট
- Low stock alert
- মেয়াদ উত্তীর্ণের alert
- প্রেসক্রিপশন অনুযায়ী ওষুধ বিতরণ
- ফার্মেসি বিলিং
- ফার্মেসি আয় ও বিনিয়োগ রিপোর্ট

### 💰 ৩.৭ বিলিং ও পেমেন্ট (Billing & Payments)

- বিল তৈরি (OPD / IPD / ল্যাব / ফার্মেসি / অপারেশন)
- পেমেন্ট কালেকশন (নগদ / কার্ড / bKash / Nagad)
- **ডুপ্লিকেট পেমেন্ট প্রতিরোধ** (Idempotency Protection)
- বকেয়া তালিকা ও ট্র্যাকিং
- বিল অনুসন্ধান ও ফিল্টার
- বিল / রসিদ PDF প্রিন্ট
- ইন্স্যুরেন্স ক্লেইম ম্যানেজমেন্ট
- অটো রসিদ নম্বর জেনারেশন
- ডিসকাউন্ট প্রয়োগ
- আংশিক ও সম্পূর্ণ পেমেন্ট
- Settlement টাইপ (Current / Due / Fire Service)

### 📊 ৩.৮ অ্যাকাউন্টিং ও ফাইন্যান্স (Accounting & Finance)

- আয়-ব্যয় ড্যাশবোর্ড
- Double-Entry জার্নাল (ডেবিট / ক্রেডিট)
- Chart of Accounts
- আয় রেকর্ড
- ব্যয় রেকর্ড (ক্যাটাগরি অনুযায়ী)
- পুনরাবৃত্ত ব্যয় (Recurring Expenses — অটো পোস্ট)
- লাভ-ক্ষতি হিসাব (Profit & Loss)
- শেয়ারহোল্ডার ম্যানেজমেন্ট ও লভ্যাংশ বিতরণ
- ডাক্তার কমিশন রিপোর্ট
- আর্থিক রিপোর্ট
- অডিট লগ

### 💼 ৩.৯ বেতন ও মুনাফা বণ্টন (Salary & Profit Sharing)

- স্টাফ তালিকা ও বেতন কাঠামো

- বণ্টন রেজিস্টার ও রিপোর্ট

### 📈 ৩.১০ রিপোর্ট ও অ্যানালিটিক্স (Reports & Analytics)

## ৫. প্রযুক্তি স্ট্যাক (Technology Stack)

| স্তর | প্রযুক্তি | উদ্দেশ্য |
|------|-----------|---------|
| **Frontend** | React 19, TypeScript, Vite | দ্রুত ও আধুনিক ইন্টারফেস |
| **Backend API** | Cloudflare Workers + Hono | নিরাপদ ও দ্রুত API |

| **File Storage** | Cloudflare R2 | রিপোর্ট, ছবি, ব্যাকআপ |
| **Caching** | Cloudflare KV | দ্রুত ডেটা lookup |
| **AI/ML** | Cloudflare AI + Vectorize | AI অ্যাসিস্ট্যান্ট |
| **Mobile** | Capacitor (Android + iOS) | নেটিভ অ্যাপ |
| **Email** | Resend API | ইমেইল পাঠানো |
| **SMS** | SSL Wireless / bNotify | SMS পাঠানো |
| **Payment** | bKash + Nagad | মোবাইল পেমেন্ট |
| **Video** | Cloudflare Realtime + Jitsi | টেলিমেডিসিন |
| **Monitoring** | Sentry + Cloudflare Analytics | ত্রুটি ও পারফরম্যান্স মনিটরিং |
| **CI/CD** | GitHub Actions | অটোমেটেড ডিপ্লয়মেন্ট |

### কেন Cloudflare?

- 🌍 **৩০০+ দেশে** edge server — বাংলাদেশেও কাছে
- ⚡ **অতি দ্রুত** response time (সাধারণত < ১০০ms)
- 🔒 **DDoS প্রতিরোধ** বিল্ট-ইন
- 💰 **কম খরচ** — সার্ভার কেনা বা ম্যানেজ করা লাগে না
- 📈 **অটো-স্কেলিং** — রোগী বাড়লে পারফরম্যান্স কমে না
