# ডাক্তার মডিউল - সম্পূর্ণ গাইড

এই ডকুমেন্টে ডাক্তার মডিউলের প্রতিটি স্ক্রিন, বাটন এবং ফিচার বিস্তারিত ব্যাখ্যা করা হয়েছে।

---

## ১. ডাক্তার ড্যাশবোর্ড (মূল স্ক্রিন)

ডাক্তার লগইন করার পর এই স্ক্রিন দেখায়। এটা ডাক্তারের daily control room।

### উপরের হেডার

| ফিল্ড | কী করে |
|--------|---------|
| **শুভেচ্ছা + ডাক্তারের নাম** | "Good Morning, Dr. রহমান" - সময় অনুযায়ী শুভেচ্ছা |
| **On Duty ব্যাজ** | সবুজ ডট - ডাক্তার এখন active আছেন |
| **বিভাগ** | ডাক্তারের specialty (কার্ডিওলজি, মেডিসিন ইত্যাদি) |
| **তারিখ** | আজকের তারিখ |
| **সেশন সিলেক্টর** | ড্রপডাউন: Morning / Evening / Chamber 1 / Chamber 2 |
| **তারিখ পিকার** | অতীত/ভবিষ্যতের দিন দেখতে পারবেন। "Today" বাটনে আজকের দিনে ফিরে যাবে |
| **৩০ সেকেন্ড ইন্ডিকেটর** | ড্যাশবোর্ড প্রতি ৩০ সেকেন্ডে auto-refresh হয় |

### ৭টা কাউন্ট কার্ড

| কার্ড | কী গোনে |
|-------|---------|
| **Waiting** | কতজন রোগী অপেক্ষা করছে |
| **In Room** | কতজন ডাক্তারের রুমে আছে |
| **Completed** | আজকে কতজন দেখা হয়েছে |
| **Report Show** | শুধু রিপোর্ট দেখাতে আসা রোগী |
| **Follow up** | ফলো আপে আসা রোগী |
| **Emergency** | জরুরি কেস |
| **Total** | আজকে সব অ্যাপয়েন্টমেন্ট |

### পরবর্তী রোগী ব্যানার

কিউতে পরবর্তী রোগী দেখায়: টোকেন নম্বর, নাম, এবং মূল সমস্যা। দ্রুত লিংক:

- **IPD** - ভর্তি রোগীদের দেখতে
- **Report Review** - রিপোর্ট দেখাতে আসা রোগীর আগের প্রেসক্রিপশন ও নতুন রিপোর্ট পাশাপাশি দেখে review complete করতে
- **Order Sets / Dictation / Referral / Certificates** - দৈনন্দিন clinical toolkit সরাসরি খুলতে
- **Schedule** - সময়সূচী দেখতে/পরিচালনা করতে
- **Fast Rx** - কিউ ছাড়া দ্রুত প্রেসক্রিপশন লিখতে

## ২. আজকের কিউ (রোগীর তালিকা)

### স্ট্যাটাস ফিল্টার ট্যাব

উপরে ক্লিকযোগ্য ট্যাব: **All | Waiting | In Room | Completed | Report Show | Follow up | Emergency | No Show | Cancelled**

প্রতিটি ট্যাবে সংখ্যা দেখায়। ডাক্তার ক্লিক করে ফিল্টার করতে পারবেন।

### প্রতিটি রোগী কার্ডে যা দেখায়

| ফিল্ড | মানে কী |
|-------|---------|
| **টোকেন #** | আজকের সিরিয়াল নম্বর (যেমন #১২) |
| **রোগীর নাম** | পূর্ণ নাম |
| **স্ট্যাটাস ব্যাজ** | Waiting / In Room / Completed ইত্যাদি |
| **অ্যালার্ট ব্যাজ** | লাল সতর্কতা - রোগীর অ্যালার্জি বা অস্বাভাবিক ল্যাব রিপোর্ট থাকলে |
| **বয়স, লিঙ্গ** | যেমন "৫৬ বছর, পুরুষ" |
| **রোগী কোড** | হাসপাতাল ID (যেমন OZZ-10245) |
| **মোবাইল** | ফোন নম্বর |
| **অ্যাপয়েন্টমেন্ট সময়** | নির্ধারিত সময় |
| **মূল সমস্যা** | রোগী কেন এসেছে (যেমন "বুকে ব্যথা, ২ দিন") |
| **ভাইটালস সারাংশ** | BP, Pulse ইত্যাদি নার্স নিলে দেখায়। না নিলে "Vitals not taken" |
| **শেষ ভিজিট** | কবে শেষ এসেছিল (যেমন "১২ ফেব্রুয়ারি ২০২৬") |
| **শেষ ডায়াগনোসিস** | শেষবার কী রোগ ধরা পড়েছিল |
| **ভিজিট টাইপ ব্যাজ** | New / Follow up / Report Show / Emergency / Free / Discounted |
| **বিলিং ব্যাজ** | Paid / Due Approved / No Charge / Pending / Unpaid |
| **অ্যালার্জি সংখ্যা** | কতটি ড্রাগ অ্যালার্জি আছে |
| **Rx সংখ্যা** | কতটি সক্রিয় প্রেসক্রিপশন আছে |
| **ল্যাব সংখ্যা** | কতটি বিচারাধীন ল্যাব অর্ডার আছে |

### প্রতিটি রোগীর অ্যাকশন বাটন

| বাটন | কী করে |
|------|---------|
| **Start Consultation** | এই রোগীর জন্য পূর্ণ workspace drawer খোলে |
| **History** | রোগীর সম্পূর্ণ চার্ট/ওভারভিউ পেজে যায় |
| **Rx** | সরাসরি নতুন প্রেসক্রিপশন পেজ খোলে |
| **Call** | Waiting → In Room করে (রোগী ভিতরে আসে) |
| **Hold** | In Room → Waiting করে (রোগীকে আবার অপেক্ষা করতে পাঠায়) |
| **Done** | রোগীকে Completed মার্ক করে (রুমে থাকলে) |
| **AI Summary** | AI-তৈরি ক্লিনিক্যাল ওভারভিউ মোডাল খোলে |
| **Reassign** | ড্রপডাউন - রোগীকে অন্য ডাক্তারের কাছে পাঠায় |

## ৪. Workspace Drawer (মূল পরামর্শ ইঞ্জিন)

ডাক্তার "Start Consultation" ক্লিক করলে এটা স্লাইড ইন হয়। এখানেই সব ক্লিনিক্যাল কাজ হয়।

### লেআউট: ৩ কলাম

#### বাম কলাম (৩/১২) - রোগীর তথ্য

**স্মার্ট ফেস শিট:**
- অ্যালার্জি সারাংশ (লাল সতর্কতা)
- সর্বশেষ ভাইটালস (BP, Pulse, Temp, SpO2, Weight)
- রোগী বর্তমানে কী ওষুধ খাচ্ছে
- শেষ ডায়াগনোসিস
- শেষ অস্বাভাবিক ল্যাব রিপোর্ট

**ল্যাব ট্রেন্ডস:** সর্বশেষ cumulative lab results একই workspace-এ দেখায়; abnormal flag থাকলে সতর্কতা দেখায়। এটি read-only context, নিজে কোনো diagnosis বা treatment বদলায় না।

**AI সারাংশ:** ভাঁজযোগ্য AI-তৈরি ক্লিনিক্যাল ওভারভিউ

**কিউ কন্ট্রোল:** Start/Done/No-show বাটন, ডাক্তার রিঅ্যাসাইন

**AI Scribe:** ভয়েস ডিক্টেশন (বিভাগ ৬ দেখুন)

#### মাঝের কলাম (৫/১২) - ক্লিনিক্যাল ডকুমেন্টেশন

**SOAP নোট ফর্ম:**

SOAP মানে: Subjective, Objective, Assessment, Plan - এটা বিশ্বব্যাপী মেডিক্যাল ডকুমেন্টেশনের স্ট্যান্ডার্ড ফর্ম্যাট।

| ফিল্ড | ডাক্তার কী লিখবেন |
|-------|-------------------|
| **Chief Complaint** | রোগী কেন এসেছে। দ্রুত চিপ আছে: জ্বর, কাশি, বুকে ব্যথা, পেটে ব্যথা, মাথাব্যথা, বমি, পাতলা পায়খানা, দুর্বলতা, ফলো আপ, রিপোর্ট শো |
| **Subjective** | রোগী নিজের কথা বলছে - কী অনুভব করছে |
| **Objective** | ডাক্তার পরীক্ষা করে যা পেলেন |
| **Assessment** | ডাক্তারের রোগ নির্ণয়/মতামত |
| **Plan** | চিকিৎসা পরিকল্পনা |

**ডায়াগনোসিস টেমপ্লেট** (এক ক্লিকে ফিল হয়):

| টেমপ্লেট | কী ফিল করে |
|----------|------------|
| **Fever (জ্বর)** | Chief Complaint: জ্বর। Assessment: Acute febrile illness। Plan: পানি, Paracetamol |
| **DM (ডায়াবেটিস)** | Assessment: Type 2 DM। Plan: Metformin, ডায়েট কন্ট্রোল, HbA1c মনিটরিং |
| **HTN (উচ্চ রক্তচাপ)** | Assessment: Essential HTN। Plan: Amlodipine, কম লোন, BP মনিটরিং |
| **Gastritis (গ্যাস্ট্রাইটিস)** | Assessment: Gastritis। Plan: Omeprazole, ঝাল-ভাজা এড়িয়ে চলুন |
| **Child fever (শিশুর জ্বর)** | শিশুর জন্য ওজন-ভিত্তিক ডোজিং টেমপ্লেট |
| **ENT** | কান/নাক/গলা পরীক্ষা টেমপ্লেট |
| **Skin allergy** | অ্যালার্জিক ডার্মাটাইটিস টেমপ্লেট |

**প্ল্যান শর্টকাট** (এক ক্লিকে যোগ হয়):
- "৭ দিন পর ফলো আপ আসুন"
- "লক্ষণ বাড়লে আগে আসুন"
- "সব আগের রিপোর্ট নিয়ে আসুন"
- "লাইফস্টাইল ও ডায়েট পরামর্শ দেওয়া হয়েছে"

**ল্যাব অর্ডার সেকশন:**
- দ্রুত চিপ: CBC, RBS, HbA1c, Creatinine, Lipid Profile, TSH
- অন্য টেস্টের জন্য সার্চ ফিল্ড
- জরুরি মাত্রা: Normal / Urgent / Emergency

**ইমেজিং অর্ডার সেকশন:**
- দ্রুত চিপ: CXR (চেস্ট এক্স-রে), USG Abdomen, USG KUB
- টাইপ ড্রপডাউন: X-Ray, Ultrasound, CT, MRI, ECG, Echocardiogram
- নোট ফিল্ড

**ফলো আপ সেডিউলার:**
- তারিখ পিকার
- সময় পিকার
- নোট ফিল্ড

**অর্ডার কার্ট:** এই সেশনে অর্ডার করা সব ল্যাব/ইমেজিং দেখায়

#### ডান কলাম (৪/১২) - প্রেসক্রিপশন ও ডিসপোজিশন

**প্রেসক্রিপশন বিল্ডার:**
- **ওষুধ সার্চ** - হাসপাতালের ফর্মুলারি থেকে সার্চ (ব্র্যান্ড নাম, জেনেরিক নাম, কোম্পানি)
- **দ্রুত যোগ পিল** - Paracetamol, Omeprazole, Cetirizine, ORS, Metformin, Amlodipine
- **ওষুধ এন্ট্রি ফিল্ড:**
  - নাম
  - ডোজ (যেমন 500mg)
  - ফ্রিকোয়েন্সি ড্রপডাউন: 1+0+0, 0+1+0, 0+0+1, 1+0+1, 1+1+1, SOS ইত্যাদি
  - সময়কাল ড্রপডাউন: ৩ দিন, ৫ দিন, ৭ দিন, ১৪ দিন, ১ মাস, Continue
  - নির্দেশনা ড্রপডাউন: খাবারের আগে, খাবারের পরে, ঘুমানোর আগে, ফাঁকে পেটে

**পরামর্শ চিপ** (এক ক্লিকে যোগ হয়):
- "প্রচুর পানি পান করুন"
- "তেল-মশলা এড়িয়ে চলুন"
- "কম লোন ডায়েট"
- "ডায়াবেটিক ডায়েট"
- "বেড রেস্ট"
- "টেস্টসহ রিপোর্ট আনুন"
- "অবস্থা খারাপ হলে জরুরি"

**লাইভ সারাংশ:** Rx আইটেম এবং অর্ডারের রিয়েল-টাইম কাউন্ট

**Repeat Last Rx:** রোগীর আগের প্রেসক্রিপশন লোড করে দ্রুত এডিট করতে

**ভর্তি/রেফার সেকশন:**
- ভর্তির কারণ, IPD নোট
- "IPD-তে ভর্তি করুন" বাটন

### স্টিকি বটম বার

| বাটন | কী করে |
|------|---------|
| **Save Rx** | প্রেসক্রিপশন draft হিসেবে সেভ করে |
| **Print** | প্রিন্ট প্রিভিউ খোলে |
| **Full Rx Page** | সম্পূর্ণ Digital Prescription পেজে যায় |
| **Full History** | রোগীর সম্পূর্ণ চার্টে যায় |
| **Follow-up** | ফলো আপ সেডিউল করে |
| **Save & Complete** | সব সেভ করে ভিজিট completed মার্ক করে |

## ৫. ডিজিটাল প্রেসক্রিপশন পেজ (পূর্ণ প্রেসক্রিপশন রাইটার)

প্রেসক্রিপশন লেখার জন্য পূর্ণ-পেজ ইন্টারফেস। প্রিন্ট/শেয়ার ফিচারসহ।

### উপরের সেকশন
- ব্যাক অ্যারো, "Digital Prescription" শিরোনাম, Rx নম্বর, তারিখ
- রোগীর তথ্য কার্ড: ছবি, নাম, কোড, বয়স, লিঙ্গ, মোবাইল, মূল সমস্যা
- ডাক্তারের তথ্য: নাম, বিশেষত্ব, যোগ্যতা

### ভাইটালস সারি
ইনপুট ফিল্ড: BP, Temperature, Weight, SpO2

### ওষুধ সেকশন (বাম ৩/৫)
- ফর্মুলারি থেকে সার্চ (autocomplete)
- দ্রুত ওষুধ পিল
- এডিটযোগ্য টেবিল: নাম, ডোজ, ফ্রিকোয়েন্সি, সময়কাল, নির্দেশনা, ডিলিট

### ক্লিনিক্যাল নোট সেকশন (ডান ২/৫)
- ডায়াগনোসিস / ICD-10 ইনপুট
- পরীক্ষা / ফাইন্ডিংস textarea
- **ল্যাব টেস্ট চেকবক্স:** CBC, Blood Sugar, Urine R/E, LFT, RFT, ECG, Chest X-Ray, Lipid Profile, HbA1c, Thyroid TSH
- রোগীকে পরামর্শ textarea
- ফলো আপ তারিখ পিকার
- **শেয়ার লিংক** - ২৪ ঘণ্টার জন্য শেয়ারযোগ্য লিংক তৈরি করে

**ওষুধ কেনার নিয়ম:** এই clinical prescription পেজ থেকে ডাক্তার delivery provider বা বিক্রেতা নির্বাচন করেন না। Final prescription পাওয়ার পর রোগী বাইরে থেকে, হাসপাতালের pharmacy থাকলে সেখান থেকে, অথবা ভবিষ্যৎ patient app-এ উপলব্ধ Ozzyl order option থেকে নিজের পছন্দে ওষুধ নিতে পারবেন।

## ৮. অর্ডার সেট (বান্ডেল টেমপ্লেট)

| টাইপ | উদাহরণ |
|------|--------|

| **ল্যাব টেস্ট** | CBC, RBS, HbA1c |
| **নার্সিং অর্ডার** | প্রতি ৪ ঘণ্টায় ভাইটালস মনিটর করুন |
| **ডায়েট অর্ডার** | ডায়াবেটিক ডায়েট |
| **নির্দেশনা** | বেড রেস্ট, ৭ দিন পর ফলো আপ |

### ক্যাটাগরি

## ৯. প্রেসক্রিপশন স্ট্যাটাস লাইফসাইকেল

```
Clinical prescription: draft → final
                         ↓
                     cancelled

Optional medicine fulfilment (separate record):
pending → partially_fulfilled → fulfilled
```

| স্ট্যাটাস | মানে কী |
|----------|---------|
| **draft** | ডাক্তার এখনো কাজ করছেন, এডিট করা যায় |
| **final** | লক, এডিট করা যায় না। রোগী দেখতে পারবে |
| **cancelled** | draft বা final থেকে বাতিল |

হাসপাতাল pharmacy ওষুধ দিলেও final prescription-এর clinical status পরিবর্তিত হয় না। Dispense, বাইরের pharmacy থেকে কেনা, অথবা ভবিষ্যৎ patient-app order হলো আলাদা fulfilment/order তথ্য।

## ১০. ড্রাগ সেফটি সিস্টেম

ডাক্তার ওষুধ লিখলে সিস্টেম স্বয়ংক্রিয়ভাবে পরীক্ষা করে:

| পরীক্ষা | কী করে |
|---------|--------|

| **ড্রাগ ইন্টারেকশন** | দুটি ওষুধের মধ্যে ইন্টারেকশন থাকলে সতর্ক করে |

মাত্রা: **Blocking** (সেভ করা যায় না) vs **Warning** (ওভাররাইড করা যায়)

## ১১.১ রিপোর্ট শো রিভিউ

`Report Review` স্ক্রিনে ডাক্তার একই সাথে দেখতে পান:

- report-show validity badge;
- আগের final prescription ও medicine;
- completed রিপোর্টের result/unit;
- এখনো pending test;
- review note এবং explicit **Mark Reviewed** action।

শুধু assigned doctor report-show appointment review complete করতে পারেন। UI কোনো রিপোর্ট দেখে নিজে থেকে diagnosis বা prescription পরিবর্তন করে না।

## ১১.২ Referral ও Medical Certificate

**Referral:** doctor route থেকে referral create/list করা যায়। Referral clinical তথ্য reception/nurse role দেখতে বা create করতে পারে না; doctor-created referral server authenticated doctor profile-এর সাথেই bind হয়।

**Medical Certificate:** Medical, Fitness, Sick Leave এবং Work Rest certificate issue করা যায়। Patient নাম/code দেখে নির্বাচন নিশ্চিত করতে হয়। Issued certificate final record; silent edit/delete নিষিদ্ধ। ভুল হলে reason দিয়ে cancel করে নতুন certificate issue করতে হবে। Create/cancel audit logged হয় এবং print preview-তে patient, certificate number, issuing doctor ও BMDC number (থাকলে) দেখায়।

## ১৩. ডাক্তার স্ক্রিনে কী দেখায় না

ডাক্তারকে রোগীর সেবায় ফোকাস রাখতে এগুলো লুকানো:
- হাসপাতালের হিসাব
- medicine order-এর কমিশন বা partner deal
- সম্পূর্ণ বিলিং লেজার
- রিসেপশন ক্যাশ সমস্যা
- ম্যানেজমেন্ট কন্ট্রোল

Ozzyl platform ভবিষ্যতে patient-app medicine order থেকে চুক্তিভিত্তিক platform revenue পেতে পারে; এটি ডাক্তারকে দেওয়া হবে না এবং prescribing suggestion/ranking-এ প্রভাব ফেলবে না। হিসাব ও operational তথ্য আলাদা অনুমোদিত admin/pharmacy workflow-তে থাকবে।
