   └─ Order → Billing → Sample Collection → Result Entry → Verification 
      → Report Generation → Dispatch
      
   With Status Tracking:
   ├─ OrderStatus: Pending → Collected → Processing → Completed
   ├─ BillingStatus: Pending → Charged → Paid → Refunded
   ├─ VerificationStatus: Unverified → Verified → Finalized
   └─ External Lab Status: Sent → Received → Processed

7. MACHINE INTEGRATION PATTERNS ✓ FOUND
   ├─ Architecture: Distributed with separate LIS Computer Server
   ├─ Communication: HTTP API calls to external LIS application
   ├─ Data Flow: Machine → LIS Server → DanpheEMR API
   ├─ Component Mapping: Via LISComponentMapModel with ConversionFactor
   ├─ Result Import: Atomic transaction (all-or-nothing)
   ├─ Sync Tracking: UpdateMachineResultSyncStatus prevents re-import
   └─ Example: Sysmex machine results → LIS Server → Danphe EMR
